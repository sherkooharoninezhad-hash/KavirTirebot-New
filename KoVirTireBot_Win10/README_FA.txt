# ربات پایش موجودی کویر تایر - Windows 10

## این نسخه چه کار می‌کند؟
- صفحه `https://kavirtire.ir/esale/products` را در مرورگر Chromium باز می‌کند.
- با اجرای برنامه، مرورگر و صفحه محصولات خودکار باز می‌شود و فهرست محصولات یک‌بار به‌روزرسانی می‌شود؛ سپس کاربر شخصاً وارد حساب می‌شود.
- هر زمان کاربر دکمه «شروع پایش» را بزند، هر ۴ ثانیه روی کنترل «بروزرسانی موجودی» کلیک می‌کند؛ محدودیت ساعت ندارد.
- فقط کارت `Special KB2000` با سایز `175/60R13` را بررسی می‌کند.
- متن‌های متداول خرید مانند «افزودن به سبد خرید» و «اضافه به سبد خرید» شناسایی می‌شوند. وضعیت فعال/غیرفعال بودن کنترل و ویژگی‌های ظاهری آن نیز بررسی می‌شود؛ متن‌های ناموجودی و کنترل‌های غیرفعال نادیده گرفته می‌شوند.

## نصب و اجرا
1. روی ویندوز ۱۰، Python 3.11 نسخه 64-bit را از python.org نصب کنید و گزینه **Add Python to PATH** را فعال کنید.
2. اینترنت را وصل کنید.
3. فایل `Run_KoVirTireBot.bat` را دوبار کلیک کنید.
4. پس از باز شدن مرورگر، خودتان وارد حساب شوید (کد پیامکی/CAPTCHA را شخصاً وارد کنید).
5. پیام ورود را در برنامه ببینید و شخصاً وارد حساب شوید.
6. پس از ورود، روی «شروع پایش» بزنید. محصول پیش‌فرض KB2000 / 175/60R13 است. برنامه در هر ساعت از شبانه‌روز کار می‌کند.

## محدودیت مهم نسخه آزمایشی
- این کد در محیط ویندوز واقعی شما اجرا یا روی حساب شما آزمایش نشده است؛ ساختار DOM و نام دقیق کنترل‌های سایت ممکن است متفاوت باشد.
- سایت ممکن است برای به‌روزرسانی موجودی، درخواست شبکه‌ای یا تأخیر خاصی داشته باشد. برنامه از دکمه قابل مشاهده خود سایت استفاده می‌کند.
- این نسخه پس از کلیک افزودن به سبد متوقف می‌شود. تعداد ۲ حلقه، سبد، نشانی و مبلغ را خودتان کنترل کنید و پرداخت را دستی انجام دهید.
- برنامه CAPTCHA، OTP، صف خرید یا هیچ سازوکار امنیتی را دور نمی‌زند.
- تشخیص متن‌های رایج خرید، وضعیت فعال/غیرفعال و ظاهر دکمه را بررسی می‌کند؛ اگر ساختار HTML سایت تغییر اساسی کند، ممکن است تنظیم مجدد لازم باشد.


## پیام راهنمای شروع
پس از باز شدن سایت، یک پیام راهنما نمایش داده می‌شود:
«سایز و مشخصات لاستیک خود را انتخاب کنید و وارد حساب کاربری خود در سایت کویرتایر بشوید و وارد صفحه خرید بشوید سپس دکمه پایش را بزنید»
اگر تیک «دیگر این پیام را نشان نده» را فعال کنید، انتخاب شما ذخیره می‌شود و در اجراهای بعدی این پیام نمایش داده نخواهد شد.


## ساخت نسخه EXE از GitHub
این بسته شامل Workflow ویندوزی است. در GitHub آن را به‌صورت ZIP بارگذاری/استخراج کنید و سپس از Actions، گزینه Build Windows EXE را اجرا کنید. خروجی در Artifact با نام KavirTireBot-Windows قرار می‌گیرد. نسخه EXE به‌صورت onedir است و پوشه Chromium را همراه خود دارد؛ کل پوشه خروجی را نگه دارید و فقط فایل exe را جدا نکنید.
